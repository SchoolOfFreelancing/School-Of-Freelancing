What is WebMCP?

This page registers tools through Chrome's experimental navigator.modelContext API. AI agents visiting this site can discover and call these tools directly — no screenshot-clicking needed.

To test, open this page in Chrome beta, open DevTools console, and run:

const mc = navigator.modelContextTesting || navigator.modelContext;
const tools = await mc.listTools();
console.log(tools);

// Call a tool:
const result = await mc.executeTool("listCourses", { category: "web" });
console.log(result);
