# auth.md

## Agent Authentication for schooloffreelancing.com

### Audience
AI agents and automated clients accessing schooloffreelancing.com.

### Registration
Agents may register at: https://schooloffreelancing.com/agent/register

### Supported Methods
- API Key: Send credentials via `Authorization: Bearer <key>` header.

### Credential Use
Credentials allow agents to access public content and submit forms on behalf of users.
